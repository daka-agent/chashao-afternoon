# 叉烧的午后

**A game by Daka**

以校园橘白猫“叉烧”为原型的 Three.js 3D 撸猫小游戏。无需登录、无广告、无后端，支持电脑与手机浏览器。

## 在线游玩

https://daka-agent.github.io/chashao-afternoon/

## 操作

- 电脑：在猫身上按住左键轻轻滑动；空白处或右键拖动旋转；滚轮缩放。
- 手机：猫身上单指滑动撸猫；空白处单指旋转；双指缩放。
- 右上角可调整声音与画质；`M` 静音，`R` 重置镜头。

摸头、挠下巴有不同反馈；尾巴比较敏感。猫也会呼吸、眨眼、看向你的手、舔爪洗脸。音量、静音和偏好只保存在当前浏览器，不上传数据。
