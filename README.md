# 叉烧的午后

**A game by Daka**

以校园橘白猫“叉烧”为原型的 Three.js 3D 云陪伴小游戏。无需登录、无广告、无后端，支持电脑与手机浏览器。

**云陪伴，不打扰。** 数字互动不作为现实流浪猫抚摸教程。现实中的校园猫请远观，不追、不抱、不主动抚摸；发现受伤或异常时，记录位置并联系学校猫协，不自行抓抱或用药。

## 操作

- 电脑：在数字猫身上按住左键轻轻滑动；空白处或右键拖动旋转；滚轮缩放。
- 手机：数字猫身上单指滑动；空白处单指旋转；双指缩放。
- 右上角 ♡ 查看“现实中的相遇”；☀ 调整声音与画质；`M` 静音，`R` 重置镜头。
- 轻轻抚摸与安静陪伴都会累积默契；数字叉烧敏感或回避时及时停手，也会得到尊重边界的反馈。

数字叉烧会呼吸、眨眼、看向你的手、舔爪洗脸。音量、静音、默契和偏好只保存在当前浏览器，不上传数据。
